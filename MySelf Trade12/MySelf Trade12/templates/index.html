Bybit API

Bybit에서 만든 API Key와 Secret을 붙여 넣고 저장하세요. 이 컴퓨터의 .env 파일에만 저장되며 다른 곳으로 보내지 않습니다.

키를 만든 계정 종류를 고르고 누르면 잔고를 조회해 키가 맞는지 알려 줍니다. 주문은 나가지 않습니다.

Gemini API 키 없음

매매 판단, 오늘의 계획, 하루 회고, 학습 자료 분석에 씁니다. 없으면 규칙 기반 전략으로 동작합니다. 저장하면 바로 연결을 확인합니다.

Google 서버가 혼잡해 기본 모델이 응답하지 않으면(HTTP 503) 예비 모델로 자동으로 넘어가고, 기본 모델이 다시 응답하면 돌아옵니다.

거래 모드

Bybit API 키를 받아 넣는 순서
  1. Bybit에 로그인합니다. 연습부터 하려면 화면을 "데모 트레이딩"으로 바꾼 뒤 진행합니다. 데모 계정의 키와 실계정의 키는 서로 다릅니다.
  2. 오른쪽 위 프로필 메뉴에서 "API"(API 관리)로 들어가 "새 키 생성"을 누르고 "시스템 생성 API 키"를 고릅니다.
  3. 권한은 "읽기-쓰기"로 하고, 통합 거래의 계약(주문, 포지션)만 체크합니다. 출금 권한은 체크하지 않습니다.
  4. 가능하면 IP 제한에 본인 IP를 넣습니다. IP 제한이 없는 키는 Bybit가 일정 기간 뒤 만료시킵니다.
  5. 만들어진 API Key와 Secret을 복사합니다. Secret은 이때 한 번만 보이므로 바로 이 화면에 붙여 넣고 "Bybit 키 저장"을 누릅니다.
  6. "Bybit 연결 확인"을 눌러 총자산이 표시되는지 봅니다.
  7. 왼쪽 메뉴 "모의투자 모드"에서 주문이 나갈 계정을 키를 만든 계정과 같은 종류로 고르고, 모의투자 스위치를 Off로 바꿉니다. 그 뒤 화면 위쪽의 자동 매매 스위치를 켜면 시작합니다.

켜 두면 매일 정한 시각에 그날의 매매 결과와 복기(잘한 점, 실수와 개선점)를 위 주소로 보냅니다. 그 시각에 프로그램(main.py)이 켜져 있어야 합니다.

보내는 방식

비밀번호나 2단계 인증 없이, 받는 주소만 넣으면 됩니다. 무료 메일 전달 서비스(FormSubmit)가 대신 보내 줍니다.

  1. 위에서 받는 주소를 추가하고 "확인 메일 보내기"를 누릅니다.
  2. 주소마다 처음 한 번은 FormSubmit에서 주소 확인 메일(제목에 Activate)이 옵니다. 그 메일의 버튼을 누릅니다. 남의 주소로 함부로 보내지 못하게 하는 절차라 건너뛸 수 없습니다. 안 보이면 스팸함을 확인합니다.
  3. "확인 메일 보내기"를 한 번 더 눌러 실제로 도착하는지 봅니다. 이후에는 매일 정한 시각에 보고서가 옵니다.

보내는 사람은 FormSubmit으로 표시되고, 보고서는 항목과 내용이 표로 정리된 형태로 옵니다. 보고서 내용이 이 서비스를 거쳐 전달된다는 점은 알아 두세요.

본인 메일 계정으로 직접 보냅니다. 보내는 사람이 본인 주소로 표시되고 미리보기와 같은 모양으로 옵니다. 대신 메일 계정의 "앱 비밀번호"가 필요합니다.

Gmail: Google 계정의 보안에서 2단계 인증을 켠 뒤 myaccount.google.com/apppasswords 에서 16자리 앱 비밀번호를 만들어 넣습니다. 네이버: 메일 서버 smtp.naver.com, 포트 465, 메일 환경설정에서 POP3/SMTP 사용을 켭니다. 다음: 메일 서버 smtp.daum.net, 포트 465, 환경설정에서 IMAP/SMTP 사용을 켭니다.
